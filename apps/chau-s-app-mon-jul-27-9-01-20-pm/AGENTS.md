# chau-s-app-mon-jul-27-9-01-20-pm

This is a Datadog App built with React, TypeScript, and Vite.

## General rules

- Keep app-specific code inside this directory.
- Frontend code runs in the browser; backend functions belong in `*.backend.ts` files.
- Do not hardcode API keys, app keys, OAuth tokens, passwords, or third-party credentials.
- Prefer the generated npm scripts in `package.json`; this scaffold uses npm.
